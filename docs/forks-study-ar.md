## 2. أقوى 8 فوركات بالنسبة لك (بهذا الترتيب)

1. **`explainroo`** — إنتاج فيديو شرح آلياً (دراسته في `docs/explainroo-study-ar.md`). الأصل الوحيد في المحفظة الذي ينتج منتجاً قابلاً للنشر مباشرة، ويعمل على أي جهاز فيه Chrome.
2. **`webdroid`** — تطبيق Kotlin يمنح Termux تحكماً كاملاً بمتصفح WebView عبر HTTP API على `localhost:8765`. **أنت عدّلته ليعمل على A10** وأضفت بناء APK آلياً. هذا أهم أصل تملكه لأنه يحوّل هاتفك إلى «يد» للوكيل.
3. **`termux-mcp`** — خادم MCP/REST داخل Termux يمنح أي وكيل تنفيذ أوامر على الهاتف ببث مباشر. القطعة الناقصة بجانب `webdroid`.
4. **`termagent`** — وكيل برمجة طرفي صغير بلغة Python، مصمّم أصلاً لـ Termux، مع أدوات قراءة/كتابة/تحرير/تشغيل، ونماذج مجانية بلا مصادقة.
5. **`web-to-app`** — «ورشة APK» كاملة على الهاتف: تحوّل مشروع ويب إلى تطبيق موقّع، مع دعم إضافات MV3 وتشغيل خوادم. يكمل `webdroid` (واجهة ← تطبيق ← تحكّم).
6. **`manimgx`** — محرك أنيميشن رياضيات/3D بواجهة Manim لكن على نواة Rust مع GPU. مكمّل مباشر لـ `explainroo` إذا أردت مشاهد رياضية معقّدة.
7. **`LocalAI`** — خادم استدلال محلي متوافق مع OpenAI (LLM/صوت/صورة). شغّله على حاسوب ووجّه إليه الهاتف؛ هذا هو الحل الواقعي لـ A10 بدل تشغيل النماذج عليه.
8. **حزمة جودة الوكلاء:** `context-mode` (تقليص مخرجات الأدوات وحفظ الذاكرة)، `ai-memory` (ذاكرة طويلة وتسليم بين الوكلاء)، `ponytail` (سلوك «أقل كود ممكن»)، `spec-kit` (تطوير مبني على مواصفة). كلها تُركّب كإضافات على الوكلاء الذين تستخدمهم.

## 4. الدراسات التفصيلية

### أ) وكلاء البرمجة (7)

#### `goose` — aaif-goose · Rust + TypeScript · Apache‑2.0 · 967MB
**ما يفعله:** وكيل برمجة مفتوح المصدر بواجهة سطح مكتب وCLI وAPI، يعمل مع أي نموذج (سحابي أو محلي)، وينفّذ ويحرّر ويختبر.
**الفكرة التقنية:** نواة بـRust + واجهة TypeScript؛ التوسّع عبر إضافات/MCP بدل تعديل النواة، ولهذا يعمل مع Ollama ونماذج محلية.
**كيف تستفيد:** بديل مفتوح لـ Claude Code على حاسوبك، ويمكن وصله بـ`LocalAI` على الشبكة المحلية بينما تتحكم به من الهاتف.
**الحالة:** متأخر 16 commit فقط، أي شبه محدّث. **التوصية:** جرّبه على حاسوب، لا على A10 (المستودع ~1GB والبناء Rust ثقيل).

#### `pi` — earendil-works · TypeScript · MIT · 82MB
**ما يفعله:** صندوق أدوات لبناء وكيل: طبقة موحّدة لمزوّدي LLM، حلقة الوكيل (agent loop)، واجهة طرفية TUI، ووكيل برمجة CLI.
**الفكرة التقنية:** monorepo بحزم منفصلة؛ الحلقة والأدوات قابلة لإعادة الاستخدام، أي أنك تستطيع بناء وكيلك الخاص فوقه بدل كتابة الحلقة من الصفر.
**كيف تستفيد:** إن أردت وكيلاً مخصّصاً (عربي/محلي/على الهاتف)، هذه أفضل نقطة بداية في المحفظة لأن الطبقات مفصولة والمقاس معقول.
**الحالة:** متأخر 752 commit. **التوصية:** اشتغل عليه؛ لكن زامن أولاً.

#### `kilocode` — Kilo‑Org · TypeScript · MIT · 695MB
**ما يفعله:** منصّة «هندسة بالوكلاء» متكاملة: وكيل داخل محرّر الأكواد مع بناء وتشغيل ومراجعة.
**الفكرة التقنية:** امتداد محرّر + طبقة وكلاء تدير الجلسات والأدوات؛ المستودع ضخم لتضمينه للتوثيق والترجمات.
**كيف تستفيد:** تجربة جاهزة لأسلوب «الوكيل داخل IDE» إذا لم تعجبك أدواتك الحالية.
**الحالة:** متأخر 495. **التوصية:** للقراءة/التجربة، ولا داعي لصيانة الـfork.

#### `orca` — stablyai · TypeScript/Electron · MIT · 1.4GB
**ما يفعله:** إدارة «أسطول» من الوكلاء (Claude Code، Grok Bot، وغيرها) من سطح مكتب/جوال/بيئة بعيدة، مع تشغيل كل وكيل على اشتراكك الخاص.
**الفكرة التقنية:** تطبيق Electron بواجهة React + طبقة تشغيل عن بعد (`cloud/`، `mobile/`، `native/`)، ومستودع عملاق لأنه يحوي كل المنصّات.
**كيف تستفيد:** مرجع معماري لتشغيل عدة وكلاء بالتوازي، وليس أداة تعمل على A10.
**الحالة:** متأخر 4418 commit — قديم جداً. **التوصية:** أعد التفكير في إبقاء الـfork؛ استخدم الأصل وأشّره بنجمة.

#### `alphacode` — dragonked2 · Rust · MIT · 27MB
**ما يفعله:** وكيل برمجة طرفي بـRust، مع نموذج مجاني مدمج أو مفاتيح Claude/GPT/Gemini/Ollama، ووضع «سرب» (swarm)، وأدوات متصفح وسطح مكتب.
**الفكرة التقنية:** ثنائي واحد سريع وقليل الاعتماديات، مع 40+ أداة وامتداد متصفح مرفق.
**كيف تستفيد:** خيار جيد لجهاز محدود الموارد إذا أردت وكيلاً بلا Node/Python ثقيل.
**الحالة:** متأخر 56. **التوصية:** جرّبه على الهاتف/الحاسوب.

#### `termagent` — loak7993-code · Python · 296KB
**ما يفعله:** وكيل برمجة طرفي صغير جداً مصمّم لـ Termux: REPL ببثّ Markdown، وأدوات `bash/read/write/edit/ls/glob`، ونماذج OpenCode Zen مجانية بلا مصادقة.
**الفكرة التقنية:** Python خالص بلا تبعيات ثقيلة، يتكلّم OpenAI Chat Completions مع tool calling، ويعمل مع أي نقطة نهاية متوافقة (OpenAI، OpenRouter، Ollama، vLLM).
**كيف تستفيد:** هذا هو «الوكيل الذي يعمل فعلاً على A10». اقرأ كوده (300KB فقط) لتتعلّم بناء حلقة وكيل، أو استخدمه مع `LocalAI` على الشبكة.
**الحالة:** متأخر 3. **التوصية:** اشتغل عليه — من أعلى أولوياتك.

#### `OpenMausBot` — milind-soni · TypeScript · Apache‑2.0 · 185MB
**ما يفعله:** بديل مفتوح لـGrok Bot: فريق من روبوتات الدردشة مع آلة افتراضية يستخدمها البوت.
**الفكرة التقنية:** تطبيق ويب + طبقة VM معزولة لكل بوت، وتوجيه لنماذجك الخاصة.
**كيف تستفيد:** مرجع لفكرة «وكيل يملك حاسوباً»، وهو نفس مبدأ `cua`.
**الحالة:** متأخر 4730 — قديم جداً. **التوصية:** للقراءة فقط، أو احذف الـfork.
