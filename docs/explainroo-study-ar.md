# دراسة تقنية لمستودع explainroo

> نسخة المستودع: `0.4.1` — رخصة MIT — المؤلف Vincent Schmalbach
> هذه النسخة عبارة عن fork على GitHub: `aehamesber-bit/explainroo` والأصل `vincentsch/explainroo`
> تاريخ الدراسة: 6 نوفمبر 2026

---

## 1. الخلاصة في عشرة أسطر

**explainroo** محرّك لإنتاج **فيديوهات شرح (Explainer Videos) بصوت معلّق ورسوم متحركة**، مكتوب بالكامل بـ JavaScript، ويعمل محلياً على جهازك بلا مفاتيح API وبلا رسوم.

الفكرة الأساسية بسيطة وقوية في الوقت نفسه: **ملفان فقط** يكتبهما إنسان أو وكيل ذكاء اصطناعي:

1. `script.md` — الكلام الذي يقوله الصوت.
2. `scenes.js` — كود JavaScript يرسم الصورة، وكل رسم يمكن ربطه بكلمة محدّدة في النص.

والباقي يتولاه المحرّك: تحويل النص إلى صوت محلياً (Kokoro)، معرفة توقيت كل كلمة (Whisper)، تخطيط الزمن، رسم الإطارات داخل Chrome بلا واجهة، توليد موسيقى ومؤثرات صوتية برمجياً، ثم تجميع كل شيء في MP4 عبر ffmpeg — مع ملفات ترجمة وصورة غلاف وفصول يوتيوب.

النتيجة: بديل مجاني ومحلي لأدوات مثل Remotion + ElevenLabs + After Effects، موجّه أساساً لـ **وكلاء البرمجة (Coding Agents)** لا للبشر، عبر ملف تعليمات ضخم اسمه `AGENTS.md` (71 كيلوبايت).

## 4. خط الأنابيب: من نصّين إلى MP4

```
script.md ──► محلّل النص ──► TTS محلي (Kokoro ONNX)
                                  │  ملف WAV لكل مشهد
                                  ▼
                        Whisper يستمع ويكتب توقيت كل كلمة
                                  │
                                  ▼
      timeline.json  ◄── lead / hold / min / pace / fps (كل الأزمنة تُقرّب للإطار)
                                  │
scenes.js ──► Chrome بلا واجهة ──► إطار PNG/JPEG لكل 1/30 ثانية (عدة صفحات متوازية)
                                  │            │
                                  │            └── كاميرا آلية + انتقالات + motion blur
                                  ▼
                    Mozart البرمجي: موسيقى + مؤثرات + خفض الموسيقى أثناء الكلام
                                  │
                                  ▼
                        ffmpeg: H.264 + AAC + تطبيع -14 LUFS
                                  │
                                  ▼
 out/video.mp4 + .srt + .vtt + .cover.jpg + .chapters.txt
```

### 4.1 الصوت (voice)

- **Kokoro‑82M** بصيغة ONNX يعمل على المعالج (لا يحتاج كرت شاشة). 54 صوتاً: 28 إنجليزياً (أمريكي/بريطاني) و26 لسبع لغات أخرى.
- الصوت يُقسَّم إلى «مقاطع» حسب الوقفات، ويُخزَّن مؤقتاً في `build/voice/<scene>.json` مع **بصمة SHA‑256** تشمل: إصدار الأنبوب، الموديل، الصوت، السرعة، النص، العلامات، وتغييرات النطق. لذلك لا يُعاد توليد إلا المشاهد التي تغيّرت — وهي ميزة عملية كبيرة أثناء التكرار.
- **التحقق من النطق** ذكي: Whisper يكتب ما سمعه، ثم `align.js` يطابق كلمة بكلمة (مع معالجة خاصة للصينية: تبسيط عبر OpenCC ومقارنة بينيين بلا نغمات، ولليابانية: تحويل الكاتاكانا). إن لم تُؤكَّد كلمة، يقترح عليك الكتابة `{shown|spoken}` مثل `{SQL|sequel}`.
- بدائل: ElevenLabs (بمفتاح)، أو تسجيل صوتك مع مطابقة عبر Whisper وffmpeg.

### 4.2 الزمن (timeline)

`timeline.js` هو عقل التوقيت: كل مشهد = `lead` (صمت قبل الكلام) + مدة الكلام + `hold` (صمت بعده). `pace` يضغط كل شيء بنسبة واحدة (0.7–1.6)، والسرعة تُطبَّق على الكاميرا والانتقالات أيضاً. كل الأزمنة تُقرَّب لشبكة الإطارات لتفادي التقطيع.

### 4.3 الرسم (engine)

- الـ API في `stage.js` غني جداً: `text`, `title`, `box`, `arrow`, `icon`, `image`, `clip`, `list`, `number`, `bars`, `lineChart`, `pie`, `code`, `terminal`, `math` (MathJax)، `group`, `focus`, `camera`, `annotate`, `draw` (رسم حر)، `sfx`.
- كل عنصر يقبل `at:` كرقم ثوانٍ، أو **كلمة منطوقة**، أو علامة `#name`، بالإضافة إلى `out` للخروج. هذه هي فكرة «الرسم يظهر على الكلمة».
- `enter` / `out` فيها حركات مرنة (spring)، و`rough.js` يعطي إحساس الرسم اليدوي في نمط `paper`.
- `layout.js` يوفّر `safe` (المنطقة الآمنة) و`row/col/grid`، والمحرّك يتكيّف تلقائياً مع الإطارات الطويلة والمربعة.
- `director.js` يحلّل مواضع العناصر مسبقاً ويخطّط الكاميرا: يبدأ واسعاً، يقترب من الشيء الجديد إن لم يتّسع له، يتابع، ثم يسحب للخلف في نهاية المشهد. بهذا لا تظهر لقطة مقطوعة في منتصفها، ولا نصّ نصفه خارج الشاشة.

### 4.4 الصوت النهائي (engine/audio)

موسيقى تُولَّد خوارزمياً (5 أنماط: warm / upbeat / calm / tech / playful) من نظرية موسيقية (`theory.js`) وآلات مُصنَّعة (`instruments.js`)، مع مؤثرات (`sfx.js`) وخفض تلقائي للموسيقى 8 ديسيبل أثناء الكلام. كل شيء بـ JavaScript حتمي (بذرة عشوائية ثابتة)، لذا نفس المدخل يعطي نفس العيّنات على كل الأجهزة — وهذا سبب اختيارهم عدم استخدام Web Audio API غير الحتمي.

### 4.5 التجميع (render + ffmpeg)

- `workers ≈ أنصاف أنوية المعالج` (بحد أقصى 8)، كل عامل صفحة Chrome مستقلة ترسم شريحة زمنية.
- **Motion blur**: 6 عيّنات لكل إطار في النسخة النهائية (يُلغى في `--draft` وGIF والشفاف) — تفصيل سينمائي نادر في أدوات كهذه.
- `--draft` ينتج نصف المقاس بجودة 0.82 للتصحيح السريع.
- تطبيع الصوت إلى −14 LUFS (معيار يوتيوب/بودكاست).

## 5. صيغة المشروع: ثلاثة ملفات

### `video.json`

```json
{
  "title": "How DNS finds a website",
  "theme": "chalk",
  "size": "tiktok",
  "voice": "af_heart",
  "language": "en",
  "pace": 1.1,
  "music": true,
  "captions": "auto",
  "watermark": false
}
```

أهم المفاتيح: `theme` (paper/clean/chalk/blueprint/midnight/editorial أو مسار ملف نمط)، `size` (youtube/shorts/tiktok/reels/vertical/instagram/linkedin/square أو `WIDTHxHEIGHT`)، `fps`، `language`، `voice`، `speed`، `pace`، `captions`، `transition` (fade/slide/wipe/zoom/brush/cut)، `camera`، `motionBlur`، `loudness`، `brand` (ألوان وخطوط وشعار لنسخة الشركة)، `watermark`.

### `script.md`

```markdown
# Title

## hook
You type {example.com|example dot com}, and a page appears. [#but] Computers
don't find each other by name.

## outro {hold=1.5 chapter="The answer"}
That makes four questions. [#blink] It takes a fraction of a second.
```

- `## id` = مشهد، ويجب أن يقابله دالة بنفس الاسم في `scenes.js`.
- `[#name]` علامة زمنية تربط الرسم بالكلام.
- `[pause 0.6]` صمت، `{shown|spoken}` لتصحيح النطق.
- خصائص المشهد: `hold`, `min`, `lead`, `transition`, `chapter`.
- `>` ملاحظات للمخرج، لا تُنطق.

### `scenes.js`

```js
export default {
  hook(s) {
    s.title('How DNS works', { at: 0 });
    s.icon('laptop', { x: 500, y: 600, size: 160, at: '#but' });
    s.arrow('a', 'b', { label: 'by name?', at: 'name' });
  },
};
```

`s` هو كائن المشهد: `s.W`, `s.H`, `s.cx`, `s.cy`, `s.safe`, `s.t`، ودوال مساعدة مثل `s.cue('word')`, `s.mark('name')`, `s.row(n)`, `s.col(n)`, `s.grid(c, r)`.

## 6. الأوامر (20 أمراً)

| الأمر | الوظيفة |
|---|---|
| `init <dir>` | إنشاء مشروع من قالب (`--theme --size --pace --language --voice --title`) |
| `voice [project]` | توليد التعليق وتوقيت الكلمات + نسبة التأكيد |
| `preview [project]` | معاينة حيّة في المتصفح تتحدّث عند الحفظ |
| `still [project] [times]` | صور PNG عند `12.5` أو `scene` أو `scene@2.4` |
| `sheet [project]` | شريحة اتصال (contact sheet) لفيديو كامل أو مشهد |
| `check [project]` | فحص التخطيط والزمن والنطق (`--view-width 854` لفحص صغر الخط) |
| `render [project]` | الفيديو + SRT/VTT + غلاف + فصول (`--format mp4|gif|webm|mov`, `--draft`, `--from/--to`, `--workers`) |
| `verify [project]` | فحص الملف النهائي: جهارة، إطارات سوداء، صمت، وضوح الصوت |
| `export [project]` | مشغّل ويب ثابت يُضمَّن بـ iframe |
| `capture [project] <url>` | التقاط موقع حي (لقطات، ألوان، خطوط، شعار، نصوص) للعرض التسويقي |
| `image / images` | صور توضيحية عبر OpenRouter (اختياري، مدفوع) |
| `voices`, `say`, `themes`, `formats`, `icons`, `doctor` | مراجع وفحص البيئة |

كل الأوامر تقبل `--json`، وهذا مقصود: **الوكيل يقرأ JSON لا نصاً بشرياً**.

## 7. أهم 12 فكرة هندسية تستحق التعلّم

1. **Local-first بالكامل**: لا سحابة، لا مفاتيح، لا قياس استخدام. الخصوصية والتكلفة صفر.
2. **النص هو مصدر الحقيقة**: التوقيت يُشتق من الصوت لا من تخمين، لذا لا يحدث انحراف بين الصورة والكلام.
3. **الوكيل في الحلقة (Agent-in-the-loop)**: المشروع لا يفترض أن المستخدم يشاهد، بل يوفّر `check` و`still` و`sheet` و`verify` — أي «عيوناً» بديلة للوكيل. هذه أنضج فكرة في المستودع.
4. **الكاميرا الآلية**: قياس مسبق لكل العناصر ثم تخطيط لقطات — بديل ذكي عن تحريك الكاميرا يدوياً.
5. **تخزين مؤقت بالبصمة**: إعادة توليد ما تغيّر فقط.
6. **صوت حتمي بـ JavaScript**: نفس النتيجة في Node وفي المتصفح، وقابل للاختبار.
7. **حالات خاصة باللغات**: espeak-ng للأصوات غير الإنجليزية، misaki لليابانية والصينية، OpenCC/بينيين لمقارنة الصينية. تفاصيل تُظهر جدّية المشروع.
8. **المناطق الآمنة للمنصات**: قوالب `safe` لـ TikTok/Reels/Shorts تحمي النص من أزرار التطبيق.
9. **تعدد المقاسات من مشروع واحد**: `--size tiktok` يخرج نسخة إضافية بلا تكرار المحتوى.
10. **أمان**: الخادم المحلي يربط `127.0.0.1` فقط، فحص اجتياز المسارات (`safeJoin`/`projectFile`)، منع الملفات المخفية، وCSP صارم في مشغّل الويب.
11. **قابلية التوسّع**: `scenes.js` وحدة ES عادية يمكنها استيراد ملفات محلية؛ الأنماط البصرية ملفات JSON ترث نمطاً مدمجاً؛ الصور والفيديو يُدمجان كمشاهد.
12. **هندسة اختبارات**: 231 حالة، 45 ملفاً، مصفوفة CI على 3 أنظمة، واختبارات متصفح فعلية للرسم والتخطيط.

## 9. القيود — وأهمها بالنسبة لك كمستخدم عربي

### ⚠️ لا دعم للعربية (حالياً)

هذا أهم استنتاج عملي في هذه الدراسة، وأكّدته من الكود لا من الإعلانات:

| الطبقة | الحالة |
|---|---|
| اللغات المسموحة | `en, es, fr, it, pt-br, hi, ja, zh` فقط (`src/project.js` يرفض أي غيرها) |
| أصوات Kokoro | لا يوجد صوت عربي بين الـ54 |
| الخطوط | السجل يحتوي لاتيني + ديفاناغاري + Noto CJK؛ لا خط عربي |
| اتجاه النص | لا معالجة RTL/Bidi ولا `ctx.direction` في المحرّك |
| التعرف الصوتي | `whisper-base.en` للإنجليزية و`whisper-small` لغيرها — لا مسار عربي |

**البدائل العملية:**

1. **الأسهل**: أن يكون الفيديو بالإنجليزية (أو إحدى اللغات الثماني) — والأدوات كلها جاهزة.
2. **نصّ عربي على الشاشة فقط**: غير موثوق — ستحصل على حروف غير متصلة واتجاه خاطئ، لأن Canvas لا يشكّل العربية دون خط مناسب ومعالجة اتجاه.
3. **تسجيل صوتك بالعربية**: ممكن تقنياً في الطبقة الصوتية، لكن مطابقة الكلمات ستفشل لأن نموذج التعرف إنجليزي/متعدد بقيود الإعداد؛ ستحتاج تعديلاً برمجياً.
4. **إضافة العربية (Fork)**: عمل مركّز لكنه محدود، ويحتاج:
   - إضافة `ar` إلى `LANGUAGES` وقائمة التحقق في `project.js`
   - خط عربي (Noto Naskh Arabic / Kufi) في `fonts/fonts.json` و`src/fonts.js`
   - دعم RTL في `engine/text.js` و`stage.js`: `direction: 'rtl'`، تقسيم ثنائي الاتجاه (bidi)، وقصّ الأسطر
   - مصدر صوت عربي: ElevenLabs (يدعم العربية) أو تسجيل أو نموذج TTS عربي
   - تمرير `language: 'ar'` إلى Whisper الصغير لضبط التوقيت، وإضافة RLM في ملفات الترجمة
   - اختبارات للاتجاه والقصّ (المستودع مبني على اختبارات، فالإضافة بلا اختبارات ستُرفض ضمناً)

### قيود أخرى
- **ليس محرّر فيديو**: لا واجهة سحب وإفلات؛ المعاينة للعرض فقط، والتحرير بالكود.
- **لا لقطات كاميرا/ممثل**: المحتوى رسومي بالكامل (يمكن دمج تسجيل شاشة داخل مشهد).
- **يعتمد على Chrome**: لا رأس للخادم (headless) لكنه يظل متصفحاً كاملاً.
- **أول تشغيل يحتاج إنترنت** لتنزيل النماذج والخطوط.
- **الأنماط محدودة بستة** ما لم تكتب نمطاً مخصّصاً.
- **العلامة المائية** تُطفأ بمفتاح، لكن الأفضل إبقاؤها أخلاقياً.

## 10. كيف تستفيد منه؟ سيناريوهات مرتّبة

### أ) صانع محتوى تقني (الأكثر مباشرة)
اصنع فيديوهات YouTube/TikTok/Reels بلا رسوم اشتراك. ابدأ من `examples/how-dns-works` وبدّل النص والرسوم. ميزة `--size` تعطيك نسخة عمودية من نفس الفيديو.

### ب) تسويق منتج SaaS
1. `capture` يسحب ألوان وخطوط وشعار ونصوص موقعك.
2. `brand` في `video.json` يوحّد الهوية.
3. `s.ui` يبني واجهات واقعية (حقول، أزرار، قوائم منسدلة) ومؤشر فأرة يكتب وينقر.
4. النتيجة عرض منتج بمظهر شركتك — راجع `examples/unspar-demo`.

### ج) توثيق تفاعلي
`export` ينتج مشغّل ويب ثابتاً يعمل داخل iframe ويكبر بحدّة (Canvas يرسم بدقة الشاشة). مناسب لصفحات docs أو صفحة هبوط.

### د) تعليم وشرح علمي
نمط `chalk` + معادلات MathJax + رسوم بيانية + كود يتغيّر خطوة بخطوة + `terminal`.

### هـ) استخدامه كمهارة لوكيل ذكاء اصطناعي
هذه هي الطريقة الرسمية:
```text
اصنع لي فيديو شرح قصيراً عن [موضوعك].
استخدم explainroo: استنسخ https://github.com/vincentsch/explainroo،
واقرأ AGENTS.md واتبع الخطوات.
```
الوكيل ينشئ المشروع، يكتب النص والرسوم، يشغّل `check` و`still`، يصلح، ثم يسلّم MP4. الملف `AGENTS.md` يحوي أيضاً قواعد كتابة التعليق (جمل 8–18 كلمة، 150 كلمة/دقيقة، لا شعارات) — وهو في الحقيقة «دليل إخراج» أكثر منه توثيقاً.

### و) كمطوّر يريد بناء شيء مشابه
هذا كنز مرجعي:
- `src/align.js`: مطابقة كلام مع نص متعدد اللغات (بما فيها حيل الصينية واليابانية).
- `engine/audio/`: توليد موسيقى ومؤثرات حتمي بـ JavaScript.
- `engine/director.js`: كاميرا آلية مبنية على قياس العناصر.
- `src/pipeline.js` + `src/render.js`: تشغيل Chrome بلا واجهة على مراحل متوازية وربطه بـ ffmpeg.
- `src/qa.js`: كيف تعطي وكيلاً ذكياً «عيوناً» للتحقق البصري.

### ز) Fork تجاري / White-label
الرخصة MIT تسمح بذلك. أطفئ العلامة المائية، اكتب نمطاً بهوية عميلك، وأضف مزوّد صوت تريده. أكبر فرصة إضافة هي **دعم العربية** (القسم 9).

## 11. خطة بدء عملية (15 دقيقة + وقت التوليد)

```bash
git clone https://github.com/vincentsch/explainroo.git
cd explainroo
npm install
node bin/explainroo.js doctor --fetch        # ينزّل النماذج (~400MB)

node bin/explainroo.js init videos/first --theme paper --title "فكرتك"
# عدّل script.md و scenes.js
node bin/explainroo.js voice  videos/first    # الصوت + التوقيت + فحص النطق
node bin/explainroo.js check  videos/first    # أصلح كل خطأ وتحذير
node bin/explainroo.js still  videos/first    # انظر إلى الإطارات
node bin/explainroo.js render videos/first --draft
node bin/explainroo.js render videos/first
node bin/explainroo.js verify videos/first
```

المخرجات في `videos/first/out/`: `video.mp4` و`video.srt` و`video.vtt` و`video.cover.jpg` وربما `video.chapters.txt`.

### ما لم أستطع تشغيله هنا
في بيئة هذه المراجعة لا توجد `node_modules` ولا صلاحية تنزيل نماذج HuggingFace (المسموح فقط GitHub وnpm وPyPI). لذلك شغّلت أوامر المراجع المستقلة عن التبعيات وتحقّقت منها فعلياً:
`themes` (6 أنماط)، `formats` (8 مقاسات)، `icons` (1854 أيقونة)، و`init` (أنشأ مشروعاً بثلاثة ملفات). أما `voice/render` فيحتاجان تثبيت التبعيات + 400MB نماذج.

- تحتاج إنتاجاً سحابياً متعدد المستخدمين (يمكن بناءه فوقه بمجهود إضافي).
